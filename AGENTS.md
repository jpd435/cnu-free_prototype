# Workspace Guidelines — CNU Free

## Automatic GitHub Synchronization
Whenever you modify, add, or delete files in this project:
1. Always stage the changes: `git add .`
2. Commit with a clear, concise commit message describing what was changed (e.g. `feat: ...`, `fix: ...`, `style: ...`).
3. Push the changes to GitHub (`git push origin main`) using `BypassSandbox: true` so the remote repository `https://github.com/jpd435/cnu-free_antigravity.git` is always synchronized in real-time.
