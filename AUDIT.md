# Phase 0 Audit — CNU Free (`AUDIT.md`)

This audit inspects all 38 views (`Screen 1` – `Screen 38`) in the V1 codebase prior to the V2 + Addendum B refactor, documenting how each screen is reached, every tappable element and its current destination in V1, and all bugs, hardcoded values, or SPEC V2 / Addendum B gaps identified.

## 2. Missing V2 Screens & Structural Gaps Identified
1. **Screen 39 (NEW — Blocked People):** Listed under `Me Hub (30)` → displays blocked users with `Unblock` button and empty state `"You haven't blocked anyone."` (`§4.5`, `§6.6`).
2. **Screen 40 (NEW — Rename Group Sheet):** Bottom sheet opened from `Group Detail (10)` `Rename` button → group name input with validation (`2–24 chars`, unique), `Save`, and `Delete group` with confirmation dialog (`§6.5`, `§6.6`).
3. **Architecture & Build Tooling:** V1 is a monolithic `public/screens.js` + `public/app.js` with Google Fonts `<link>`. V2 + Addendum B refactors into modular ES modules under `src/` (`src/main.js`, `src/clock.js`, `src/store.js`, `src/router.js`, `src/time.js`, `src/overlap.js`, `src/privacy.js`, `src/validators.js`, `src/seed.js`, `src/ocr-mock.js`, `src/ui/*`, `src/screens/*`), Vite build outputting to `dist/`, self-hosted `@fontsource/bricolage-grotesque` & `@fontsource/manrope`, and Capacitor iOS (`com.cnufree.app`).
